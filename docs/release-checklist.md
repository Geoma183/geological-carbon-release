# Public release checklist

This is a repository preparation checklist, not a completed data release.

- [ ] Confirm the exact manuscript and supporting-information versions.
- [ ] Reconcile all released figures and tables with those manuscript versions.
- [ ] Verify third-party data licenses and redistribution permissions.
- [ ] Keep observed, estimated, reconstructed, missing, and not-applicable values distinct.
- [ ] Record geographic coverage, units, source versions, and accounting boundaries.
- [ ] Exclude supervisor comments, credentials, private correspondence, and unverified outputs.
- [ ] Document executable code, environment, and validation checks before claiming reproducibility.
- [ ] Select appropriate code and data licenses before releasing under a reusable license.
- [ ] Create a versioned release and archive to Zenodo only after validation.
